Why You'll Love It

Fine-grained access control, built into Odoo.

Lock down the backend, the portal, a webhook or any custom route to just the addresses you trust — no reverse-proxy config, no server access. Everything lives in one simple list of rules.

🛡️

Allow-list or Deny-list

Each rule either allows only the listed addresses, or denies them — your choice, per route.

🧭

Flexible Route Matching

Match a route by exact path, by prefix, or with a regular expression — and optionally against the full URL.

🌐

IPv4, IPv6, CIDR & Masks

Enter a single address, a network with a subnet mask, or CIDR notation — both IPv4 and IPv6 are supported.

🧩

Header Conditions

Add optional HTTP header conditions that must hold for a rule to apply — for fine-tuned targeting.

🔢

Ordered, First-Match Wins

Rules are evaluated in sequence and the first match decides. Routes no rule matches are left untouched.

⚙️

No Server Access Needed

Manage everything from Settings — no reverse-proxy, firewall or command-line configuration required.

Key Features
✓  Allow-only-listed or deny-listed — configurable per rule.
✓  Route matching by exact path, prefix, or regular expression.
✓  IP entries as a single address, network + subnet mask, or CIDR — IPv4 & IPv6.
✓  Optionally match against the full URL rather than the path alone.
✓  Optional HTTP header conditions that must hold for the rule to apply.
✓  Rules evaluated in sequence order; the first match decides.
✓  A route no rule matches is left alone — not a default-deny firewall.
✓  Lightweight — managed entirely from Settings > Technical.
Up & Running in 3 Steps
1
Open Settings > Technical > IP Access Rules and create a rule.
2
Set the route, choose Allow or Deny, and add your IP / CIDR entries.
3
Order your rules with the sequence handle — the first match wins. Done!
Example
Allow /odoo only from 203.0.113.0/24 — everyone else is blocked from the backend.
A Guided Tour

Set up a rule in a couple of clicks.

1

Find It Under Technical

The module adds an IP Access Rules entry under Settings > Technical — right where Odoo's security tools live.

2

Build a Rule in Seconds

Set the route and matching type (exact / prefix / regex), choose Allow Only Listed IPs or Deny Listed IPs, and add your IP / CIDR entries. Optional Header Conditions and a Sequence control ordering.
